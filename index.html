Wprowadzenie

Cel projektu

Projekt Zen Garden pokazuje potęgę CSS poprzez zmianę wyglądu tej samej strony HTML przy pomocy różnych arkuszy stylów. Celem jest zrozumienie, że treść i forma mogą być od siebie całkowicie oddzielone.

Inspiracja

Inspiracją dla projektu jest klasyczny CSS Zen Garden, który od lat pokazuje, że prosty HTML może być podstawą niezliczonych wizualnych interpretacji.

Struktura strony

Elementy główne

Strona zawiera nagłówek, sekcje z treścią, stopkę oraz dynamiczny przełącznik styli. Układ jest responsywny, dostosowany do ekranów komputerów i urządzeń mobilnych.

Dostosowanie do użytkownika

Każdy styl CSS zmienia nie tylko kolory, ale też układ elementów, interlinię, marginesy oraz hierarchię wizualną, by maksymalnie poprawić czytelność i doświadczenie użytkownika.

Przykładowa lista

Kluczowe zasady UX/UI

  • Używaj spójnych kolorów i typografii.
  • Zadbaj o odpowiedni kontrast.
  • Dostosuj układ do różnych rozdzielczości ekranów.
  • Minimalizuj ilość rozpraszających elementów.
  • Zapewnij intuicyjną nawigację.
